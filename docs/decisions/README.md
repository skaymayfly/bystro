# Architektonická rozhodnutí (ADR)

Jedno rozhodnutí = jeden soubor `NNNN-kratky-nazev.md`, číslováno vzestupně.

```
# NNNN — Název rozhodnutí

Datum: YYYY-MM-DD
Stav: navrženo | přijato | nahrazeno (NNNN)

## Kontext
Proč se rozhoduje, jaké jsou možnosti.

## Rozhodnutí
Co jsme zvolili.

## Důsledky
Co to znamená pro kód, provoz a další kroky.
```
